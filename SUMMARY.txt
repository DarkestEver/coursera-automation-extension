✨ WHAT THIS EXTENSION DOES
================================================================================

SCANNING:
  • Finds all content links on Coursera course pages
  • Categorizes by type: lectures, supplements, labs, assignments
  • Extracts course info (courseId, courseSlug)
  • Shows summary of findings

PROCESSING:
  • Marks items as completed via Coursera API
  • Batch processes with safety delays
  • Real-time progress tracking
  • Error reporting per item

UI FEATURES:
  • Clean popup interface with gradient theme
  • Modal confirmation showing breakdown
  • Visual progress bar
  • Item-by-item result display
  • User ID persistence

SUPPORTED TYPES:
  ✓ Video Lectures (/lecture/)
  ✓ Supplements (/supplement/)
  ✓ Ungraded Labs (/ungradedLab/)
  ✓ Assignments (/assignment-submission/)

================================================================================
🔧 HOW IT WORKS
================================================================================

ARCHITECTURE:
  Popup UI
    ↓ (chrome.tabs.sendMessage)
  Content Script
    ↓ (DOM scanning & API calls)
  Coursera Servers
    ↓ (HTTP responses)
  Progress Display

LINK TYPES MAPPING:
  /lecture/       → POST /api/opencourse.v1/.../videoEvents/ended
  /supplement/    → POST /api/onDemandSupplementCompletions.v1
  /ungradedLab/   → POST /api/onDemandSupplementCompletions.v1
  /assignment/    → POST /api/onDemandSupplementCompletions.v1

API FLOW:
  1. User enters User ID
  2. Scans page for all /learn/ links
  3. Gets courseId from page data (data-click-value)
  4. Extracts itemId from URL path
  5. For each link, calls appropriate API with userId + courseId + itemId
  6. Displays success/failure for each item

❓ FINDING YOUR USER ID (3 WAYS)
================================================================================

METHOD 1 - NETWORK TAB (BEST):
  1. Open course page
  2. F12 → Network tab
  3. Scroll or click on page
  4. Look for request to api.coursera.org
  5. Click request → Payload tab
  6. Find "userId": "12345678"
  7. Copy the number

METHOD 2 - SEARCH PAGE SOURCE:
  1. Open course page
  2. Ctrl+F
  3. Search: "userId"
  4. Look for pattern: "userId":"12345678"

METHOD 3 - BROWSER CONSOLE:
  1. Open course page
  2. F12 → Console tab
  3. Paste: document.body.innerText.match(/userId["\s:]+(\d+)/i)
  4. Copy the number from result

ISSUE: Extension not showing
FIX:   chrome://extensions → Toggle ON

ISSUE: "Not on Coursera page" message
FIX:   Navigate to https://www.coursera.org/learn/[course]/home/welcome

ISSUE: "No links found"
FIX:   Refresh page (Ctrl+R), then try again

ISSUE: API calls failing (401/403)
FIX:   Refresh course page, possibly log out/in to Coursera

ISSUE: Can't find User ID
FIX:   Use Network tab method (most reliable)
