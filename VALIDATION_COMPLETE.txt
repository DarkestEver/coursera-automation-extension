================================================================================
KNOWN LIMITATIONS (Not Bugs)
================================================================================

1. courseId Auto-Detection
   - Only works if page has data-click-value attribute
   - Some courses might not expose this
   - Workaround: Manual entry (future enhancement)

2. Coursera Session Dependency
   - Requires active Coursera login
   - Session expiration causes 401 errors
   - Workaround: Refresh Coursera page

3. Rate Limiting
   - Coursera might rate-limit rapid requests
   - 500ms delay between items should be safe
   - Workaround: Increase delay if needed

4. Link Detection
   - Only finds links in left navigation area
   - Hidden/lazy-loaded content might be missed
   - Workaround: Scroll to load more content
